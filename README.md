# SERGIK

Underground electronic music from Phoenix.

SERGIK is a producer, DJ, curator, and organizer. The sets are groove-forward and minimal-leaning, built for warehouses, after-hours rooms, and dance floors that change with the room.

**Live site:** https://sergikdropz.com
